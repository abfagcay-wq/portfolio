RPG Game Project

A text-based role-playing game developed in Java

Game Features

  • Character creation with customizable stats
  • Turn-based combat system with multiple enemy types
  • Inventory management and item collection
  • Exploration and narrative progression
  • Leveling system and skill development
  • Save/Load functionality for game progress

How to Run

1. Ensure Java Development Kit (JDK) is installed on your system

2. Save the code below as Fagcayang_RPG.java

3. Compile: javac Fagcayang_RPG.java

4. Run: java Fagcayang_RPG
